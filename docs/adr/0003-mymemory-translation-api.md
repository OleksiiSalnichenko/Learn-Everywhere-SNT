# 0003. MyMemory Translation API без ключа, з шаблонним прикладом як fallback

## Контекст

Потрібен переклад слів (укр/нім/англ) і приклад речення до кожного слова,
без власного бекенду і без збору/зберігання API-ключів.

## Рішення

Переклад іде через MyMemory Translation API (HTTP GET, без ключа). З відповіді
беруться до двох унікальних перекладів з найвищою якістю (`match`) із масиву
`matches[]`. Якщо серед `matches[]` є сегмент, чиє джерело — повне речення
(не саме слово), його переклад стає прикладом; якщо такого немає —
підставляється проста шаблонна фраза мовою словника ("Das ist <слово>." /
"This is <слово>."), позначена `isGenerated = true`.

## Чому

Сервіс без реєстрації і без ключа — пряма вимога користувача з брифінгу;
альтернативи на кшталт Google Translate API чи DeepL відкинуті самим бри­фом
через цю вимогу. Шаблонна фраза-заглушка обрана замість порожнього поля чи
помилки, коли `matches[]` не містить речення: порожній приклад порушив би
вимогу "до кожного слова — одне речення", а виклик окремого сервісу
генерації речень (LLM) визнаний зайвим ускладненням для цього масштабу
застосунку. Мітка `isGenerated` збережена окремим полем, а не просто
відкинута, щоб згенеровані приклади можна було відрізнити й замінити пізніше.

## Наслідки

Якість перекладу й прикладів обмежена тим, що вже є в пам'яті перекладів
MyMemory — рідкісні слова можуть отримати слабкий приклад або впасти на
шаблон. Сервіс безкоштовний, але без SLA і без ключа: немає способу підняти
ліміт запитів чи звернутись у підтримку при простої; недоступність мережі
обробляється на рівні UI (повідомлення + повторити), а не офлайн-кешем
перекладів. Заміна на платний сервіс із ключем — це не лише новий
HTTP-клієнт, а й UI для введення й зберігання ключа, якого зараз немає.
