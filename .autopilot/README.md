# Як читати цю теку

- `dashboard.html` — відкривається сам на початку збірки; можна й подвійним кліком.
  Етапи, прогрес, час, що лишилось. Оновлюється сам, поки збірка йде.
  `index.html` поряд — той самий файл під іншим іменем, щоб дашборд відкривався
  за коротким адресом. Окремо його відкривати не потрібно.
- `<дата>-<проєкт>/` — тека однієї збірки. Дата в імені — день, коли збірка почалася,
  тому теки йдуть по порядку згори вниз. Суфікс `--wip` значить «ще робиться»;
  коли збірка здана, суфікс знімається. Всередині:
  - `<дата>-brief.md` — твоя початкова задача, слово в слово, і «Доповнення» — все,
    що ти сказав пізніше. Сам текст задачі не переписується.
  - `manifest.md` — список вимог і що з кожною сталося.
  - `spec.md` — специфікація.
  - `tickets/` — таски, на які розбита збірка (якщо збірка дрібна, їх немає).

Якщо збірка перервалась — скажи агенту «продовж автопілот», він підніме стан звідси.
